Thank you for proposing a new feature! This template follows a light RFC structure to help maintainers understand your proposal.

**What happens next:**

1. Maintainers review your proposal
2. If accepted, maintainers will create a draft RFC specification on a dedicated branch
3. You'll be granted permissions to collaboratively edit the specification
4. A tracking issue will be created to monitor RFC progress through review
5. Once approved, additional specifications (TSY, SPEC, ERR) will be generated as needed
6. This issue will remain open as the high-level tracker for all related specifications (RFC, TSY, SPEC, ERR)
